### katelabs

A point-in-time record of what the crypto market is being told: each headline is scored by a language model within minutes of publication and never revised, aggregated into a daily index per coin, tested, costed and traded.

- Paper: [The flow, not the headline: point-in-time LLM sentiment and the cross-section of cryptocurrency returns](https://ssrn.com/abstract=7669918), SSRN working paper, October 2026.
- Data: a public three-month sample on [Hugging Face](https://huggingface.co/datasets/katelabs/crypto-news-scored); full history, live feed and API on [katelabs.io/docs](https://katelabs.io/docs).
- Live record: every real trade matched one to one against the simulator, [note 3](https://katelabs.io/research/live-vs-simulator); all simulated deals per coin on [alpha evidence](https://katelabs.io/alpha-evidence).
